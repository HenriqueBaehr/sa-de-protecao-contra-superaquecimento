# Sistema de automação contra superaquecimento

1- A prensa térmica opera com uma temperatura máxima indicada, caso este valor seja ultrapassado, um sistema de resfriamento deverá ser ligado automaticamente.
2- A solução para resolver tal problema é desenvolver um sistema para que limite a temperatura máxima que pode chegar. Ligando uma ventoinha para diminuir a sua temperatura caso ela ultrapasse a temperatura normal.
3- Componentes utilizados: Sensor de temperatura, Arduíno, cooler fan 12v, bateria, jumpers, 1 resistor 10k.
4- Faz-se primeiro a leitura dos sensores, delimita-se a temperatura normal do sensor que acionará uma ventoinha caso a temperatura normal seja ultrapassada. Caso contrário, permanecerá inerte.
